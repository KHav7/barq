# barq: Free Barcode & QR Code Generator

100% client-side. Nothing uploaded, nothing tracked. No ads.

**Barcodes:** EAN-13, EAN-8, UPC-A, Code 128 with artistic shape masks and custom colors.

**QR Codes:** URLs, text, contact info with logo overlay, and recent history.

**Export:** SVG, PNG, JPG. Batch ZIP download.
