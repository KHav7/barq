About barq

Free, fast, and private barcode & QR code generator. Create standard barcodes (EAN-13, EAN-8, UPC-A, Code 128) or artistic QR codes — all generated directly in your browser. Nothing is uploaded, nothing is tracked. Download as SVG, PNG, or JPG.

Format Reference

  • EAN-13: 12-13 digits. Global retail standard (GTIN).
  • EAN-8: 7-8 digits. Compact codes for small products.
  • UPC-A: 11-12 digits. US/Canada retail standard.
  • Code 128: Alphanumeric. Logistics and supply chain.
  • QR Code: Up to 2953 bytes. URLs, text, contact data. Higher error correction = more damage resistant.
